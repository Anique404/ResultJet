EXCEL FILE FORMAT (IMPORTANT)
================================================================================

Your Excel files MUST follow this format:

File Name:    [ClassName].xlsx  (e.g., 10th.xlsx)
Location:     CLASS_DATA/ folder

Columns (in order):
  1. RollNo          (numeric)
  2. StudentName     (text)
  3. FatherName      (text)
  4-N. Subject columns in pairs:
       • [SubjectName]      → Marks obtained
       • [SubjectName]_Max  → Maximum marks

EXAMPLE (10th.xlsx):
┌──────┬──────────────┬────────────┬─────────┬──────────────┬──────────────┐
│RollNo│StudentName   │FatherName  │Physics  │Physics_Max   │Chemistry...  │
├──────┼──────────────┼────────────┼─────────┼──────────────┼──────────────┤
│1     │Ali Raza      │Raza Ahmed  │68       │75            │72...         │
│2     │Sara Khan     │Khan Sahab  │70       │75            │68...         │
└──────┴──────────────┴────────────┴─────────┴──────────────┴──────────────┘

KEY RULES:
  ✓ Each subject MUST have a _Max column
  ✓ Max marks can vary per subject and per class
  ✓ Marks cannot exceed max marks (system will warn and cap)
  ✓ All numeric values must be valid numbers

PASS/FAIL CRITERIA (CRITICAL)
================================================================================

RULE 1 - SUBJECT PASS/FAIL:
  • Percentage = (Marks Obtained / Max Marks) × 100
  • FAIL if percentage < 33%
  • PASS if percentage ≥ 33%

RULE 2 - OVERALL RESULT:
  • Student FAILS if ANY subject is below 33%
  • Student PASSES only if ALL subjects are 33% or above
  • Even with 95% in 4 subjects, one failing subject = OVERALL FAIL

RULE 3 - GRADING SYSTEM (Based on percentage):
  • A+ (Outstanding)  : 90-100%
  • A  (Excellent)    : 80-89%
  • B  (Good)         : 70-79%
  • C  (Satisfactory) : 60-69%
  • D  (Pass)         : 50-59%
  • E  (Pass w/ Help) : 33-49%
  • F  (Fail)         : Below 33%

TROUBLESHOOTING
================================================================================

Problem: "Excel file not found"
Solution:
  • Create file named EXACTLY: [ClassName].xlsx
  • Place it in CLASS_DATA/ folder
  • Use Excel 2007+ format (.xlsx, not .xls)

Problem: "Column not found" error
Solution:
  • Check first 3 columns: RollNo, StudentName, FatherName
  • Check subject columns have _Max columns
  • Ensure column names don't have extra spaces
  • Check column names are spelled correctly

Problem: No PDFs generated
Solution:
  • Check Excel file is not empty
  • Check all marks are numeric
  • Check max marks are greater than 0
  • Check OUTPUT folder has write permission

Problem: Marks show as 0 or incorrect in PDF
Solution:
  • Check Excel data is numeric (not text)
  • Check _Max columns have correct max marks
  • Check no marks exceed their respective max marks

Problem: Application won't start
Solution:
  • Try running as Administrator
  • Right-click → Run as Administrator
  • Check Windows Defender or antivirus isn't blocking it
  • Check your system meets minimum requirements

For more help, see README.txt
